# 整合包汉化工具

把 Minecraft 整合包里的英文文本扫出来，翻成中文，再打包成游戏能直接加载的资源包。全程在本地跑，不上传你的整合包，也不写注册表。

当前版本：**v1.0.9**　系统：Windows 10 / 11 64 位

## 下载哪个

到本仓库的 **Releases** 页面，两个包选一个：

- **单文件版**：只有一个 exe，解压后双击就能开，适合大多数人。
- **目录版**：exe 旁边带一个 `_internal` 文件夹。不是自解压，启动快一点，杀软误报也少一些。

两个版本功能一样，存档和译文格式也通用，随时可以换。

## 怎么用

1. 打开整合包**上级文件夹所在位置**。
   要选到含 `mods` 文件夹的那一层，不是 `.minecraft` 本身，也不是 `mods` 里面。
2. 点击一个模组，开始翻译。
   左边只会列出真正有文字可翻的模组，纯功能模组不会占位置。
3. 三种翻译方式，根据你的情况自行修改。
   - 本地模型：在「设置 → 翻译引擎」里填 Ollama / LM Studio / llama.cpp 的地址，点一下就能探测。
   - 免费在线翻译：不用装模型、不用 Key，适合少量补译或应急。质量一般，有每日字数上限，整包别用它硬跑。
   - 手工汉化：把待译文本分段复制出去翻，再按行粘回来；也可以直接在中文列里改。
4. 快完成了，打包一下。
   点「生成资源包」，重启游戏就生效。原始 jar 不会被动，所有中间数据都在整合包目录的 `_hanhua_tool` 里，不想要了删掉就行。

第一次启动会弹一个几页的教程；看过之后可以从「设置 → 使用教程」再看。所有能点的按钮，鼠标放上去都会说明它是干什么的。

## 翻译质量大概什么样

- **本地模型**：质量取决于你用的模型。7B 级别日常够用，专有名词建议配合词汇表统一；显存够的话换更大的模型会明显好一些。
- **免费在线翻译**：短句、物品名还行，长句和带颜色码、占位符的文本容易出问题。工具会做格式校验，不合规的不会硬写进去，但整包全量不推荐。
- **自己的在线 API**：按你选的模型来，通常比免费网页接口稳定。
- **手工/社区译文**：最稳，尤其是任务书和手册这类长文本。

翻译完建议点一下「检查译文」，把残留英文、占位符错位、空译文过一遍，再生成资源包。

## 常见问题

**杀毒软件报毒？**
PyInstaller 打包的 exe 容易遇到这种误报。首次运行如果跳出 Windows SmartScreen，点「更多信息 → 仍要运行」；杀软里把 exe 加白名单。介意的话直接用目录版。

**需要装 Python 吗？**
不需要。两个发布包都是打包好的，双击 exe 就能用。

**会改我的整合包吗？**
不会动原始 jar。译文、进度和报告都在 `_hanhua_tool` 里，资源包单独生成在 `resourcepacks` 或 `config/openloader/resources`。

**支持哪些版本？**
1.13 以后的整合包（语言文件是 `.json` 的那种）。1.12 及更早的 `.lang` 不支持。

**免费接口别人下载了还能用吗？**
能，它走的是公开网页翻译接口，不需要填 Key。但这类接口本来就不稳定，可能限流或改规则；工具里做了失败提示和格式校验，真被封了只能换本地模型或自己的 API。
